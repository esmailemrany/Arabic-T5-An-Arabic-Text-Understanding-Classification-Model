Contributing Guidelines

Thank you for your interest in contributing to this project.

How to Contribute

Contributions that improve the project's code, documentation, reproducibility, or performance are welcome.

Reporting Issues

- Describe the issue clearly.
- Include relevant error messages when possible.
- Explain how the issue can be reproduced.

Suggesting Improvements

- Explain the proposed improvement.
- Describe its expected benefits.
- Provide supporting details where applicable.

Submitting Changes

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your modifications.
4. Test your changes.
5. Submit a Pull Request with a clear description.

Contribution Scope

Relevant contributions may include:

- Arabic NLP improvements.
- Tokenizer development.
- Data preprocessing improvements.
- Model training and evaluation.
- Documentation and reproducibility.

Thank you for helping improve this project.
